DURE 구현 발표

발산하던 운영을 두레 속 수렴

운영자, 강사, 사용자의 핵심 흐름을 하나의 웹 서비스로 연결했습니다.

대본

저희 DURE는 마을 기반 수업 운영에서 발생하는 여러 업무를 하나의 흐름으로 모으기 위해 만든 웹 서비스입니다. 기존에는 수업 개설, 강사 관리, 자료 공유, 출석 기록, 수업 메모, 참여자 의견 수집 같은 업무가 각각 다른 도구나 메시지로 흩어져 관리되는 경우가 많았습니다. 저희는 이처럼 발산하던 운영 업무를 DURE 안으로 수렴시키는 것을 목표로 했습니다. 그래서 이번 구현에서는 운영자, 강사, 사용자 각각의 역할에 맞는 핵심 기능을 실제 웹 환경에서 동작하도록 만들었습니다.

운영자 사이드

자신만의 운영 공간 만들기

워크스페이스는 마을이나 기관이 수업을 운영하는 기본 단위입니다.

움짤 삽입 영역
워크스페이스 개설
대본

먼저 운영자 사이드입니다. 운영자는 DURE에서 자신만의 운영 공간, 즉 워크스페이스를 만들 수 있습니다. 워크스페이스는 하나의 마을이나 기관이 수업을 운영하는 기본 단위입니다. 운영자는 이름과 기본 정보를 입력해 운영 공간을 개설하고, 이후 이 공간 안에서 수업과 구성원을 관리하게 됩니다. 이 기능을 통해 DURE는 단순한 수업 목록 서비스가 아니라, 각 운영 주체가 독립적으로 사용할 수 있는 운영 플랫폼 구조를 갖게 됩니다.

02 / 06

운영자 사이드

원터치 수업 개설

운영자가 수업을 개설하는 순간 하나의 수업 운영 흐름이 시작됩니다.

움짤 삽입 영역
수업 개설
대본

워크스페이스를 만든 뒤에는 운영자가 수업을 개설할 수 있습니다. 수업명, 설명, 기간, 정원, 강사, 공개 여부 같은 수업 정보를 입력하면, 해당 워크스페이스 안에 수업이 생성됩니다. 여기서 중요한 점은 수업이 단순히 화면에만 추가되는 것이 아니라, 이후 강사의 수업 관리, 자료 업로드, 출석 기록, 사용자 탐색 흐름과 연결된다는 점입니다. 즉, 운영자가 수업을 개설하는 순간 DURE 안에서 하나의 수업 운영 흐름이 시작됩니다.

03 / 06

강사 사이드

수업 운영 기록 남기기

출석 상태와 수업 메모를 수업 단위의 운영 이력으로 정리합니다.

움짤 삽입 영역
출석과 수업 메모
대본

다음은 강사 사이드입니다. 강사는 자신에게 배정된 수업에 들어가 출석을 기록할 수 있습니다. 수강생별로 출석, 지각, 결석 상태를 저장하고, 수업별 출석 이력을 관리할 수 있도록 구현했습니다. 또한 수업 메모 기능을 통해 그날의 진행 내용이나 특이사항을 남길 수 있습니다. 이 기능들은 강사가 수업을 진행하면서 매번 따로 기록해야 했던 운영 정보를 DURE 안에 남기도록 만든 부분입니다. 수업이 끝난 뒤에도 출석과 메모가 수업 단위로 정리되어 확인될 수 있습니다.

04 / 06

강사 사이드

수업 자료를 한 곳에서 관리

강사가 수업 자료를 업로드하고 수업 페이지에서 확인할 수 있습니다.

움짤 삽입 영역
자료 업로드
대본

강사는 수업 자료도 직접 업로드할 수 있습니다. 자료 업로드 기능은 파일을 선택해 수업에 연결하고, 업로드된 자료를 수업 페이지에서 확인할 수 있도록 구현했습니다. 초기에는 외부 스토리지 업로드 흐름을 분리해 설계했지만, 실제 SSR 환경에서 안정적인 업로드를 위해 서버 액션 기반의 직접 업로드 방식으로 정리했습니다. 이를 통해 강사는 수업별 자료를 DURE 안에서 관리할 수 있고, 운영자는 자료 공유가 개별 메신저나 외부 링크로 흩어지는 문제를 줄일 수 있습니다.

우리 모드

마을을 살펴보고 의견을 제안하기

사용자가 여러 마을과 공개 수업을 탐색하고 참여 접점을 만들 수 있습니다.

움짤 삽입 영역
마을 탐색과 의견 제출
대본

마지막은 사용자, 즉 우리 모드입니다. 사용자는 여러 마을을 탐색하고, 공개된 수업 정보를 확인할 수 있습니다. 관심 있는 수업이나 마을이 있다면 의견을 제출하거나 참여 의사를 남길 수 있도록 구현했습니다. 이 흐름은 DURE가 운영자와 강사만을 위한 내부 관리 도구에 머무르지 않고, 실제 참여자와 연결되는 접점을 갖도록 만든 부분입니다. 결과적으로 DURE는 운영자가 수업을 만들고, 강사가 수업을 운영하고, 사용자가 마을과 수업을 발견해 의견을 남기는 하나의 연결된 웹 서비스로 구현되었습니다.
