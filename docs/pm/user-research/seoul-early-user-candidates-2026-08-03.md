## 권장 접촉 순서

1. **성동발달장애인평생교육센터**: DURE의 반·참여자·출석·수업 메모 구조와 가장 직접적으로 맞는다.
2. **마포장애인가족지원센터**: 장기/단기 프로그램이 섞여 있어 실제 운영 복잡성을 발견하기 좋다.
3. **피치마켓**: 여러 기관에 같은 다회차 교육을 확산하는 운영 모델이라, 한 조직 파일럿을 넘어 반복 가능한 제품 요구를 검증하기 좋다.

## 첫 미팅의 제안 범위

- 30분 인터뷰에서 먼저 `모집 → 반 배정 → 회차 운영 → 출석·특이사항 기록 → 내부 공유·보고`의 실제 도구를 보여 달라고 요청한다.
- 데모는 인터뷰 뒤에 10분만 보여주고, “AI가 무엇을 할까”보다 “이번 주 미처리 업무를 어떤 근거로 알려주면 믿을 수 있는가”를 묻는다.
- 파일럿은 한 프로그램, 2~4주, 운영자 1~2명으로 제한한다.
- 장애인·청소년의 실제 개인정보는 초기 탐색 단계에서 받지 않고, 가명/테스트 데이터로 흐름을 먼저 검증한다.

## 해석상 주의

- 공식 사이트에 프로그램과 연락처가 있다는 사실은 현재 활동과 접촉 가능성의 근거다.
- 인력 규모, 엑셀·수기 사용, 업무 고충, 도입 의사는 공개 자료로 확인되지 않았다. 이는 모두 인터뷰에서 검증할 가설이다.
- 점프와 공공 위탁 센터는 제품 적합성이 높아도 기존 시스템·보안·조달 절차 때문에 실제 파일럿 전환은 느릴 수 있다.
