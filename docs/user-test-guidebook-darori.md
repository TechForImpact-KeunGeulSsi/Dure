# 다로리인 유저 테스트 가이드북

이 문서는 Zoom으로 진행하는 다로리인 유저 테스트의 단일 운영 가이드입니다. 참여자에게는 배포 URL, 계정, 태스크만 공유하고, 진행자는 사전 준비, 관찰 포인트, 종료 후 확인 항목까지 함께 사용합니다.

## 1. 테스트 준비

### 테스트 환경

- 워크스페이스: `다로리인 유저테스트`
- 앱 URL: `https://dure-user-test-dure-s-projects.vercel.app`
- Supabase 프로젝트: `dure-user-test`
- Supabase project ref: `sufvrkvlpebjeksimfix`
- Supabase URL: `https://sufvrkvlpebjeksimfix.supabase.co`
- 테스트 데이터 생성: 유저 테스트 전용 Supabase 환경변수로 `npm run seed:darori` 실행
- seed dry-run 확인: `node scripts/seed-darori-user-test.mjs --dry-run`

참여자는 `http://localhost:3000`으로 접속할 수 없습니다. Zoom 유저 테스트에서는 반드시 배포된 앱 URL을 공유합니다.

### 테스트 계정

| 역할 | 이메일 | 비밀번호 | 사용 목적 |
|---|---|---:|---|
| 대표 운영자 | `darori.owner@test.local` | `123456` | 전체 운영 현황, 수업 생성, 자료 업로드, 참여자 메모 |
| 강사 | `darori.instructor@test.local` | `123456` | 담당 수업 확인, 출석 입력, 수업 메모 |
| 그룹 운영자 | `darori.group@test.local` | `123456` | 내부 QA용 그룹 제한 권한 확인 |

참여자에게는 본인이 사용할 역할 계정만 안내합니다. 한 브라우저에서 운영자와 강사 세션을 연속 테스트할 때는 로그아웃 후 다시 로그인합니다.

### 준비물

- 업로드 테스트 파일: `녹음 준비 안내.txt`
- 파일 내용 예시:

```text
녹음 전 준비 안내입니다.
각자 맡은 가사를 한 번씩 읽어 보고, 조용한 대기 공간에서 순서를 기다려 주세요.
```

## 2. Seed 데이터 기준

seed 스크립트는 다음 데이터를 만듭니다.

| 항목 | 수량 | 비고 |
|---|---:|---|
| 테스트 계정 | 3 | 대표 운영자, 강사, 그룹 운영자 |
| 워크스페이스 | 1 | `다로리인 유저테스트` |
| 마을학교 그룹 | 7 | 문서 원본의 7개 그룹 |
| 참여자 | 32 | 한국어 가명, 각 그룹에 분배 |
| 수업 | 9 | 진행 중 5, 완료 2, 진행 전 2 |
| 자료 | 2 | `.txt` 자료를 Supabase Storage에 업로드 |
| 기존 출석 | 2회차분 | `방과후, 캠핑` 1-2회차 |
| 기존 메모 | 2개 | 캠핑/음원출시 수업 메모 |
| 최근 활동 | 8개 | 자료, 출석, 메모, 멤버 이벤트 |

수업 수량은 진행 중 5개, 완료 2개, 진행 전 2개로 총 9개입니다.

## 3. 진행자 운영 순서

### 사전 준비

1. 유저 테스트용 Vercel 배포가 `dure-user-test` Supabase 프로젝트를 바라보는지 확인합니다.
2. `APP_URL`이 참여자에게 공유할 배포 URL과 동일한지 확인합니다.
3. 유저 테스트 전용 Supabase 환경변수로 `npm run seed:darori`를 실행해 데이터를 초기화합니다.
4. 배포 URL에서 운영자 계정으로 로그인해 `다로리인 유저테스트` 워크스페이스가 보이는지 확인합니다.
5. 업로드 테스트 파일 `녹음 준비 안내.txt`를 참여자에게 전달할 준비를 합니다.

### Zoom 진행 방식

1. 테스트 시작 전 참여자에게 Zoom 링크와 앱 URL을 모두 전달합니다.
2. 참여자는 본인 PC의 브라우저에서 앱 URL을 직접 엽니다. 진행자 화면 공유로 대신 조작하지 않습니다.
3. 진행자는 필요할 때만 Zoom 화면 공유 요청을 하며, 조작 방법을 먼저 설명하지 않고 참여자가 어디서 막히는지 관찰합니다.
4. 참여자가 멈추면 “지금 무엇을 찾고 계신가요?”처럼 의도를 묻고, 바로 정답을 안내하지 않습니다.
5. 태스크별 완료 여부, 헷갈린 문구, 찾지 못한 버튼, 되돌아간 화면을 기록합니다.
6. 비밀번호나 개인정보가 보일 때는 화면 공유를 잠시 중단하게 안내합니다.
7. 테스트가 끝나면 인터뷰 질문을 묻고, 진행자는 데이터 변경 항목을 확인합니다.

### 참여자에게 보내는 안내문

```text
안녕하세요. 다로리인 유저 테스트에 참여해 주셔서 감사합니다.

테스트는 Zoom을 켠 상태에서 각자 브라우저로 아래 링크에 접속해 진행합니다.

앱 URL: https://dure-user-test-dure-s-projects.vercel.app

진행자가 안내한 역할 계정으로 로그인해 주세요.
테스트 중 정답을 찾으려 애쓰기보다, 실제로 사용한다고 생각하고 편하게 조작해 주세요.
헷갈리는 부분은 말로 설명해 주시면 됩니다.
```

### 배포 환경변수 기준

```text
NEXT_PUBLIC_SUPABASE_URL=https://sufvrkvlpebjeksimfix.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=<dure-user-test anon key>
SUPABASE_SERVICE_ROLE_KEY=<dure-user-test service_role key>
SUPABASE_JWT_SECRET=<dure-user-test JWT secret>
APP_URL=<참여자에게 공유할 Vercel 배포 URL>
```

`SUPABASE_SERVICE_ROLE_KEY`와 `SUPABASE_JWT_SECRET`은 문서나 채팅에 공개하지 않습니다.

## 4. 운영자 세션

권장 시간: 30-40분  
로그인 계정: `darori.owner@test.local`

### 태스크 1. 운영 현황 파악하기

상황: 여러 마을학교 수업이 동시에 운영되고 있습니다. 전체 운영 현황을 빠르게 확인해야 합니다.

수행:

1. 로그인 후 `다로리인 유저테스트` 워크스페이스로 들어갑니다.
2. 왼쪽 메뉴에서 `홈`을 확인합니다.
3. 진행 중인 수업, 최근 활동, 가까운 일정이 어디에 보이는지 살펴봅니다.
4. `참여자·수업 관리`로 이동한 뒤 `수업 관리` 탭을 엽니다.
5. 수업 목록에서 진행 중, 진행 완료, 진행 전 수업이 어떻게 구분되는지 확인합니다.

완료 기준:

- 현재 운영 중인 수업을 말할 수 있습니다.
- 수업 목록에서 상태와 연결 그룹을 확인할 수 있습니다.

관찰 포인트:

- 홈에서 가장 먼저 보는 정보
- 최근 활동과 수업 상태가 현황 파악에 주는 도움
- `참여자·수업 관리` 안에서 `수업 관리` 탭을 찾는 데 생기는 막힘

### 태스크 2. 새 수업 `반찬을 부탁해` 만들기

상황: `노는 엄마들` 마을학교에서 요리 만들기 수업을 새로 운영하기로 했습니다.

수행:

1. `참여자·수업 관리`의 `수업 관리` 탭으로 이동합니다.
2. `새 수업` 버튼을 누릅니다.
3. `수업 이름`에 `반찬을 부탁해`를 입력합니다.
4. `연결 그룹`에서 `노는 엄마들`을 선택합니다.
5. `담당 강사`는 비워둡니다.
6. `운영 상태`는 `진행 전`으로 둡니다.
7. `반복 회차 수업`을 선택합니다.
8. 시작일은 테스트 당일 이후 가까운 날짜로 선택합니다.
9. 시작 시간은 `14:00`, 종료 시간은 `16:00`으로 입력합니다.
10. 반복 요일은 편한 요일 1개를 선택합니다.
11. 종료 조건은 `총 회차 수`, 값은 `4`로 입력합니다.
12. `참여자 배정`에서 `노는 엄마들` 참여자가 후보로 보이는지 확인합니다.
13. 참여자는 기본 선택 상태를 유지합니다.
14. `수업 만들기`를 누릅니다.
15. 목록에서 `반찬을 부탁해`가 생성되었는지 확인합니다.

완료 기준:

- `반찬을 부탁해` 수업이 생성되었습니다.
- `노는 엄마들` 그룹과 참여자가 연결되었습니다.
- 총 4회차 일정이 생성되었습니다.

### 태스크 3. 기존 수업 출석 현황 확인하기

상황: `방과후, 캠핑` 수업의 출석 상태를 확인해야 합니다.

수행:

1. 수업 목록에서 `방과후, 캠핑`을 엽니다.
2. 수업 상세에서 `참여자 현황` 탭을 확인합니다.
3. 참여자별 출석 수, 최근 출석 상태, 특이사항을 살펴봅니다.
4. 자료 또는 홈 탭으로 이동해 수업 정보가 한곳에 모여 있는지 확인합니다.

완료 기준:

- `방과후, 캠핑` 참여자의 출석 현황을 확인했습니다.
- 어떤 참여자가 출석 관리 대상인지 이해했습니다.

### 태스크 4. 수업 자료 확인하고 새 자료 업로드하기

상황: `마을학교 음원출시` 수업에 녹음 준비 안내 자료를 추가해야 합니다.

수행:

1. 수업 목록에서 `마을학교 음원출시`를 엽니다.
2. `수업 자료` 탭으로 이동합니다.
3. 기존 자료 `가사 초안 활동지.txt`를 확인하고 다운로드 버튼을 눌러봅니다.
4. `자료 업로드` 버튼을 눌러 `녹음 준비 안내.txt`를 업로드합니다.
5. 업로드한 자료가 목록에 추가되었는지 확인합니다.

완료 기준:

- 기존 자료를 확인했습니다.
- `녹음 준비 안내.txt`가 수업 자료 목록에 추가되었습니다.

### 태스크 5. 참여자 메모 수정하기

상황: `다로리마을학교` 참여자 중 한 명에게 다음 운영자가 참고할 메모를 남깁니다.

수행:

1. `참여자·수업 관리`로 이동합니다.
2. `참여자 관리` 탭을 선택합니다.
3. 그룹 필터에서 `다로리마을학교`를 선택합니다.
4. 참여자 1명을 고릅니다.
5. `수정` 버튼을 누릅니다.
6. `메모`에 `녹음 활동 참여 의사 높음`을 입력합니다.
7. `저장`을 누릅니다.
8. 목록에서 메모가 반영되었는지 확인합니다.

완료 기준:

- 다로리마을학교 참여자 1명의 메모가 수정되었습니다.
- 참여자 목록에서 메모를 확인할 수 있습니다.

## 5. 강사 세션

권장 시간: 20-30분  
로그인 계정: `darori.instructor@test.local`

### 태스크 1. 담당 수업 확인하기

상황: 강사는 본인이 맡은 수업만 중심으로 확인해야 합니다.

수행:

1. 강사 계정으로 로그인합니다.
2. `다로리인 유저테스트` 워크스페이스로 들어갑니다.
3. `홈`에서 담당 수업 목록을 확인합니다.
4. `마을학교 음원출시`와 `방과후, 캠핑`이 보이는지 확인합니다.
5. `방과후, 캠핑` 수업으로 들어갑니다.

완료 기준:

- 강사가 담당하는 수업 2개를 확인했습니다.
- `방과후, 캠핑` 강사 콘솔에 들어갔습니다.

### 태스크 2. `방과후, 캠핑` 3회차 출석 입력하기

상황: 3회차 수업이 끝났고, 강사는 참여자 출석을 기록해야 합니다.

수행:

1. `출석부` 탭을 엽니다.
2. 회차 선택 영역에서 `3회차`를 선택합니다.
3. 참여자 목록을 확인합니다.
4. 대부분은 `출석`으로 두고, 1명은 `부분 출석`, 1명은 `결석`으로 바꿉니다.
5. 필요하면 참여자별 메모를 입력합니다.
6. `출석 저장`을 누릅니다.

완료 기준:

- 3회차 출석이 저장되었습니다.
- 출석, 부분 출석, 결석 상태가 섞여 있습니다.

### 태스크 3. 수업 메모 작성하고 자료 확인하기

상황: 강사는 회차별 진행 상황을 남기고, 다른 담당 수업의 자료도 확인해야 합니다.

수행:

1. `방과후, 캠핑`의 `출석부` 화면에서 `수업 메모` 영역을 찾습니다.
2. 아래 문장을 입력합니다.

```text
밧줄놀이 활동에 전반적으로 적극적으로 참여했고, 다음 회차에는 안전 안내 시간을 조금 더 확보하면 좋겠습니다.
```

3. `메모 저장`을 누릅니다.
4. 상단 탭 또는 홈을 통해 `마을학교 음원출시` 수업으로 이동합니다.
5. `수업 자료` 탭에서 기존 자료가 보이는지 확인합니다.

완료 기준:

- `방과후, 캠핑` 3회차 수업 메모가 저장되었습니다.
- `마을학교 음원출시` 자료 목록을 확인했습니다.

## 6. 테스트 후 확인 항목

운영자 세션 이후:

- `반찬을 부탁해` 수업이 생성됨
- `노는 엄마들` 참여자가 수업에 배정됨
- `마을학교 음원출시`에 `녹음 준비 안내.txt` 자료가 추가됨
- 다로리마을학교 참여자 1명의 메모가 `녹음 활동 참여 의사 높음`으로 변경됨

강사 세션 이후:

- `방과후, 캠핑` 3회차 출석이 저장됨
- `방과후, 캠핑` 3회차 수업 메모가 저장됨

참여자 인터뷰 질문:

- 오늘 가장 편하다고 느낀 흐름은 무엇이었나요?
- 기존 방식과 비교했을 때 시간이 줄어들 것 같은 업무가 있었나요?
- 어디에서 다음에 뭘 해야 할지 헷갈렸나요?
- 수업, 참여자, 출석, 자료가 연결되어 보였나요?
- 실제 운영에 쓰려면 꼭 추가되어야 할 정보나 기능은 무엇인가요?
